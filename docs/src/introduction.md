# Introduction

This book teaches security analysis of Android applications: APK reversing (Java and native), deobfuscation, rooting, dynamic instrumentation, network traffic interception, syscall tracing (eBPF) etc.

The source code is available [here](https://github.com/gemesa/android-security-handbook).

🚧 The book is still under construction. New chapters will be added and the existing ones might be modified.
