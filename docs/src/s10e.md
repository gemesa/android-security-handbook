## Prerequisites

1. enable the following in developer options:
   - OEM unlocking
   - USB debugging
2. unlock the bootloader:
   - power off the phone
   - hold Vol Down + Bixby then connect USB cable to PC
   - warning screen appears, long press Vol Up to unlock
   - the phone wipes data and reboots
3. after reboot:
   - during setup:
      - if it is stuck at Checking info..., go back and click Dont copy again
   - go back into developer options
      - check if OEM is unlocked
      - enable USB debugging

## Rooting

### Patch the AP File with Magisk

1. extract `SAMFW.COM_SM-G970F_TMH_G970FXXSGHWC2_fac.zip`:
    - `AP_xxx.tar.md5`
    - `BL_xxx.tar.md5`
    - `CP_xxx.tar.md5`
    - `CSC_xxx.tar.md5`
    - `HOME_CSC_xxx.tar.md5`
2. `adb push AP_G970F*.tar.md5 /sdcard/Download/`
3. `adb install app-release.apk` (Magisk)
4. Magisk --> Install --> Select and Patch a File --> select the AP file
5. Magisk will create the patched `magisk_patched-XXXXX.tar` in the same folder
6. `adb pull /sdcard/Download/magisk_patched-XXXXX.tar`

Note: Magisk produces a patched AP file that is much smaller than the original.

### Flash FW + patched AP with Odin

1. open Odin 3.14.1-3B Patched
2. uncheck "Auto Reboot"
3. boot phone into Download Mode: hold Vol Down + Bixby, then connect USB
4. load files into Odin slots:
   - BL slot --> `BL_xxx.tar.md5`
   - AP slot --> `magisk_patched-XXXXX.tar`
   - CP slot --> `CP_xxx.tar.md5`
   - CSC slot --> `CSC_xxx.tar.md5` *(not `HOME_CSC`)
5. click Start and wait for PASS (green)
6. do not reboot yet

### Flash TWRP recovery with Odin

1. restart phone and go back to download mode
2. restart Odin
3. in Odin: uncheck all slots
4. in Odin: clear the AP slot and load the TWRP `.img.tar` into AP
5. confirm "Auto Reboot" is still unchecked
6. click Start and wait for PASS (green)

### Boot into TWRP

1. with USB cable still connected, manually boot into TWRP recovery:
   - hold Vol Down + Power --> after vibration, release Vol Down
   - immediately hold Vol Up + Vol Down + Power (I accidentally released Vol Down for a sec and then it went to TWRP mode I think) or Vol Up + Bixby + Power
   - I dont know if this is necessary: after the splash screen, release Power only, continue holding Vol Up + Bixby for ~1 second, then release
2. you should now be in TWRP
3. if TWRP prompts to keep system read-only, swipe to allow modifications

Note 1: Entering TWRP without a USB cable connected does not work reliably. Always keep the cable connected during this step.

Note 2: You will know you are at the right point to release buttons when you see the Samsung logo with red warning text (the unlocked bootloader warning), not the plain Samsung logo.

### Wipe and install files in TWRP

#### Standard wipe

1. in TWRP tap Wipe --> Advanced Wipe --> Dalvik / ART Cache + Cache then Swipe to Wipe
2. This clears cache and dalvik cache. Skipping this step is the most common cause of bootloops.

#### Format data (fixes storage size issue)

1. in TWRP: Wipe --> Format Data
2. type `yes` and confirm
3. this fixes the issue where internal storage shows as 32GB instead of 128GB
4. after formatting: Reboot --> Recovery

### Install zip files in TWRP (order matters)

- `adb push multidisabler-samsung-3.5-corsicanu.zip /sdcard/`
- `adb push Ambasadii_Cruel-HVJ5-G97xF-v8.2-S-magisk.zip /sdcard/`
- `adb push TWRP_Bootlogo_patcher_v1.6.zip /sdcard/`

#### First boot and Magisk setup

1. in TWRP: tap Reboot --> System
2. complete the standard Android setup wizard
3. reboot the phone
4. the Magisk app will appear (it can take a few minutes)
5. open Magisk
   - if it says "Upgrade to full Magisk to finish the setup. Download and install?" then click OK
5. open Magisk --> tap OK when prompted to reboot and complete installation
6. the phone reboots
7. root is active
