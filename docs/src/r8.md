# R8

## Use case

R8 optimizes and obfuscates the Java code in release builds.

## Explanation

- Code shrinking
- Method inlining
- Class merging
- Obfuscation

## Usage

`build.gradle.kts`:

```
...
    buildTypes {
        release {
            optimization {
                enable = true
            }
        }
    }
...
```

`gradle.properties:`

```
...
android.r8.gradual.support=true
...
```
